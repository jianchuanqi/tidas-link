# 字段边界

| 信息 | 所在层次 |
| --- | --- |
| 完整 LCA 数据集 | TIDAS |
| LCI、LCIA 结果及 PCF Profile | TIDAS-Link |
| 结果实际采用的上游结果或背景数据 | TIDAS-Link `calculationInputs` |
| PACT 字段格式和传输方法 | PACT Adapter |
| 消息、授权、流程、存储和审计 | 具体系统 |

## 结果字段

- 结果编号、修订、状态和数据责任方；
- 评价对象和参考量；
- 系统边界、时期和地域；
- LCI 清单流、LCIA 环境影响结果和补充参数；
- 建模、质量、不确定性、核验和限制；
- 必要的 TIDAS 对象引用。

## 计算输入字段

- 输入编号；
- 供应商结果或背景数据引用；
- 来源类型；
- 实际采用数量；
- 数量或单位换算；
- 在目标计算中的位置；
- 必要的限制说明。

## 系统字段

消息编号、发送方、接收方、接口地址、传输时间、认证、授权、分页、交付状态、
重试、错误、存储和审计信息由具体系统承载。
